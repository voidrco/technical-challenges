# Fictional Operations inbox

It is Monday 09:00 in São Paulo. You have 90 minutes before checking priorities with Operations Lead. The CEO's two process requests can start as a pilot this week. The following six requests arrived. Describe the next action, not a completed outcome you cannot verify. All names and documents are fictional.

| ID | Request | Known evidence and timing |
| --- | --- | --- |
| I01 | New joiner starts Tuesday at 09:00 | Manager confirmed the start. Laptop allocation is still unconfirmed and the access request has no IT approval. Do not grant access yourself. |
| I02 | Provider invoice is due Tuesday | Invoice NF-081 says R$ 2,400; the service order says R$ 2,000. A second email contains the same invoice number. No explanation or payment approval was supplied. Do not pay or book it as reconciled. |
| I03 | Candidate asks about an interview on Wednesday | One message says 14:00, another says 15:00. No confirmed calendar invitation is in the packet. The hiring owner needs to validate the slot. Do not promise a time or select the candidate. |
| I04 | Person requests Tuesday off using extra time | The work approval is only mentioned in a chat; the structured record is pending. No coverage is confirmed. Use the work/time-off packet to propose the control; this inbox note is not authorization. |
| I05 | CEO wants all processes and trainings organized | The ten-item inventory has duplicate versions, missing owners and restricted records. There is no approved rollout deadline. Propose a small first scope and a review checkpoint. |
| I06 | Provider renewal is Thursday | The contract owner has not confirmed renewal. A request says “please send the signed renewal today,” but no approved version or signature exists. Coordinate with Operations Lead and the legal/contract owner; do not sign or claim it is approved. |

Include all six requests in one table. Any extra dates, owners or service levels you propose must be labeled as proposed. Write one missing-information request and one leadership update using the issues above.
