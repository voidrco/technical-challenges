# AI Tech Intern Technical Challenge

**Take-Home Challenge**

Time: 3 days | Role: AI Tech Intern

---

## Overview

This challenge evaluates your ability to work with AI tools, write clean code, and solve problems creatively. You'll demonstrate fundamental programming skills, curiosity about AI, and capacity to learn quickly — the core traits we look for in our interns.

**Important:** This is an intern-level challenge. We don't expect production-ready code or expert-level AI knowledge. We want to see how you think, learn, and approach new problems.

## Challenge Components

### Part 1: AI Integration Script (Code Deliverable)

Create a simple Python or JavaScript script that uses an LLM API (OpenAI, Anthropic, or any other) to solve a practical problem.

**Choose ONE of the following options:**

#### Option A: Test Case Generator

Build a script that:
- Receives a feature description as input (e.g., "User login with email and password")
- Uses an LLM to generate test case suggestions
- Outputs structured test cases (title, steps, expected result)

#### Option B: Bug Report Analyzer

Build a script that:
- Receives a bug report text as input
- Uses an LLM to extract and structure information (severity, affected area, reproduction steps)
- Outputs a formatted summary

#### Option C: Code Documentation Helper

Build a script that:
- Receives a code snippet as input
- Uses an LLM to generate documentation/comments
- Outputs the documented code

**Technical Requirements:**

| Requirement | Description |
|-------------|-------------|
| Language | Python or JavaScript/TypeScript |
| API Integration | Any LLM API (OpenAI, Anthropic, Google, etc.) |
| Error Handling | Basic error handling for API failures |
| Input/Output | Clear input method and readable output |
| README | Instructions on how to run your script |

**What We're Looking For:**

| Aspect | What to Include |
|--------|-----------------|
| Code Quality | Clean, readable code with meaningful variable names |
| Functionality | Script works as expected with different inputs |
| Prompt Engineering | Thoughtful prompt design that produces useful outputs |
| Documentation | Clear README with setup and usage instructions |

---

### Part 2: Learning Reflection (Written Deliverable)

Write a short document (1-2 pages) answering the following questions:

1. **What did you learn?**
   - What was new to you in this challenge?
   - What concepts did you have to research?

2. **Challenges faced**
   - What was the hardest part?
   - How did you overcome it?

3. **AI Usage Reflection**
   - How did you use AI tools to complete this challenge?
   - What prompts worked well? What didn't?
   - What did you learn about working with LLMs?

4. **Ideas for Voidr**
   - Based on what you learned about Voidr, suggest ONE idea for how AI could improve test automation
   - Keep it simple — we want to see your thinking, not a business plan

**Format:** PDF, Google Docs, or Markdown file

---

### Part 3: AI Usage Documentation (Required)

You **should** use AI tools to complete this challenge. Document your AI usage:

**Include:**

- Which AI tools you used (ChatGPT, Claude, Copilot, etc.)
- How you used AI for:
  - Learning new concepts
  - Debugging your code
  - Writing documentation
  - Designing prompts
- Example prompts that were particularly effective
- What you learned about using AI as a learning tool

We're evaluating your ability to leverage AI as a productivity multiplier — a key skill for this role.
